À propos de Le Sosie

Une question, deux méthodes indépendantes : Python et SQL travaillent sur les mêmes dépenses. Le backend compare les montants et les dépenses utilisées. En cas de divergence, aucun résultat n’est présenté comme validé.

Documentation et aide

Importez un CSV avec les colonnes date, description, categorie et montant. Posez ensuite une question sur le total, une catégorie ou une période précise. Chaque import ajoute des lignes aux dépenses existantes.

Le mode direct nécessite un serveur compatible avec le flux d’événements. Le parcours classique reste disponible sans cette option.
